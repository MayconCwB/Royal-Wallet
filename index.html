📲 Instalar como Aplicativo Real (PWA)

O Minha Carteira possui manifesto autêntico para funcionar como aplicativo completo no seu smartphone (tela cheia, sem barra de navegação, rápido e offline).

🤖 No Android (Chrome / Edge / Samsung): Toque no botão verde flutuante "📲 Instalar aplicativo" ou vá no menu do navegador (⋮) > Instalar aplicativo. (Caso apareça "Adicionar à tela inicial", ele também abre em tela cheia via PWA standalone).
🍎 No iPhone / iPad (Safari): Toque no ícone de Compartilhar (quadrado com seta) > Adicionar à Tela de Início.
💻 No Computador (Chrome / Edge): Clique no ícone de monitor com seta na barra de endereço para instalar como aplicativo de área de trabalho.
